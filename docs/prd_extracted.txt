Employee Training & Certification Management System ΓÇö Frontend
1. Project Overview
Build a fully functional Employee Training & Certification Management System frontend using React with Create React App. The application will initially use a local mock database implemented with JSON/static data and React state. The data model must be structured so it can later be replaced by a Java/Spring Boot backend and relational database with minimal changes.
The application has two roles:
Admin
Employee
The implementation must cover the complete workflow in this document. All buttons, forms, navigation, CRUD operations, authentication, role handling, tabs, state updates, validation, and route protection must actually work. Do not create placeholder or partially functional features.

4.2 Employee

Employees must not access the Admin Dashboard, employee management, other employees' records, deletion, or role management. Direct navigation to an admin URL must also be blocked.
5. Authentication
Login flow:
User opens /login.
User enters email and password.
The application checks credentials against the local mock data.
Valid Admin credentials route to /admin/dashboard.
Valid Employee credentials route to /employee/dashboard.
Invalid credentials remain on the login page and display a clear error.
Authentication state must contain at minimum:
id
name
email
role
Logout must clear authentication state, return the user to /login, and prevent access to protected pages.

8. Add Employee
Provide an Add Employee button that opens a functional form.
Required fields:
Name
Email
Password
Designation
Role
Role should default to Employee, while the Admin may explicitly create an Admin.
Validation:
Required fields cannot be empty.
Email must have a valid format.
Email must be unique.
Password cannot be empty.
Designation cannot be empty.
Invalid submissions must not create an employee.
Successful creation must add both the employee record and corresponding login/user record, then update the dashboard immediately.
9. Edit Employee
Edit must open a form populated with existing employee data.
Editable fields:
Name
Email
Designation
Role
Password does not need to be changed through the normal edit operation.
Role changes must update the corresponding authentication/user record and immediately reflect in the dashboard.
10. Delete Employee
Delete must require confirmation.
If confirmed:
Remove the employee.
Remove the corresponding user/login record.
Remove associated certificates and assessments so orphaned records cannot appear elsewhere.
Update the dashboard immediately.
If cancelled, no data may change.
